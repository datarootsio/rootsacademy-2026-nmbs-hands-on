# RootsAcademy 2026 — NMBS Hands-On End-to-End ML

1. Install Git LFS before cloning (the historical delay data needs it):

   ```bash
   git lfs install
   git clone https://github.com/datarootsio/rootsacademy-2026-nmbs-hands-on.git
   cd rootsacademy-2026-nmbs-hands-on
   ```

   Already cloned without Git LFS? Run `git lfs pull` to fetch the real file.

2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Launch Jupyter and open the first notebook:

   ```bash
   jupyter notebook notebooks/assignment_notebooks/01_data_understanding_DIY.ipynb
   ```
